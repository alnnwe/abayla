# Описание датасета Abayla

## Формат (CSV, UTF-8)

| Поле | Значения | Назначение |
|---|---|---|
| id | уникальная строка | идентификатор примера |
| text | текст сообщения | вход модели |
| label | `scam` / `not_scam` | основной класс |
| scheme | `bank_police_impersonation`, `phishing`, `relative_in_trouble`, `fake_ad`, `investment`, `other_scheme`; для `not_scam` — `none` | тип схемы, нужен для анализа ошибок |
| language | `ru` / `kk` / `mixed` | язык текста |
| source_type | `real` / `reconstruction` / `synthetic` / `synthetic_demo` | происхождение |
| source_id | строка | откуда пример: версия набора, номер опроса, ссылка на публичное описание схемы |
| template_group | строка | группа шаблона: оригинал, перевод и перефразировки должны иметь ОДНУ группу |
| annotation_status | `verified` / `pending` / `disputed` | в обучение идут только `verified` |

Проверка формата: `abayla/data/schema.py::validate` (обязательные колонки, допустимые значения, пустые тексты,
дубликаты id, согласованность `label` и `scheme`, группы с обоими классами).

## Типы источников

- **real** — реальное сообщение, переданное владельцем с согласием и обезличенное до попадания в набор.
- **reconstruction** — текст, восстановленный по публичному описанию схемы (предупреждения банков, полиции,
  новости). В `source_id` указывается источник описания.
- **synthetic** — написанный или сгенерированный пример. Результаты на синтетике показываются отдельно.
- **synthetic_demo** — демонстрационный набор этого репозитория.

## Демонстрационный набор `abayla_demo_v1`

- 286 строк, 141 группа шаблонов (в среднем 2 текста на группу: RU-оригинал, KZ-перевод, иногда перефразировка).
- Классы: scam 145, not_scam 141. Языки: ru 149, kk 133, mixed 4.
- Схемы (scam): имитация банка/полиции 37, фишинг 28, родственник в беде 23, другие 23, объявления 19, инвестиции 15.
- Статусы: verified 280, disputed 4, pending 2 (спорные исключены из обучения).
- Все тексты написаны вручную автором проекта по общеизвестным описаниям схем. Банки, имена, номера и домены
  вымышленные: `example.com/.org/.net`, адреса `203.0.113.x` (диапазон для документации), номера `+7 000 …`.
- «Проверка» (`verified`) в демо-наборе означает проверку одним автором, а не согласие двух разметчиков.

### Ограничения демо-набора (обязательно назвать на защите)

1. Это не реальные сообщения. Стиль одного автора, нет опечаток, сленга, длинных цепочек переписки.
2. Объём мал: test = 40 текстов (20 групп). Доверительные интервалы метрик широкие.
3. Мошеннические тексты в среднем длиннее (120 против 80 символов): классификатор «только по длине» даёт
   ROC-AUC ≈ 0.79 на test. Модель может частично опираться на длину.
4. Правила (модель №1) писал тот же человек, что и тексты, включая test. Оценка правил оптимистична.
5. Казахские тексты — переводы русских; естественная казахская переписка может сильно отличаться.

## Как предотвращается утечка данных

- Разбиение по `template_group` 70/15/15, стратифицированное по классу на уровне групп (`group_split`).
- Тест `tests/test_data.py::test_group_split_no_leakage_and_proportions` проверяет, что ни одна группа
  не попала в две выборки, а перевод всегда лежит вместе с оригиналом.
- TF-IDF обучается только на train (внутри `Pipeline.fit`).
- Аугментация (`--augment`) применяется только к train и только после разбиения; validation и test
  побайтово совпадают с вариантом без аугментации.
- Пороги выбираются только на validation; test используется один раз в `abayla.evaluation.evaluate`.

## Импорт своего CSV

```python
from abayla.data.prepare import import_user_csv
df = import_user_csv("my.csv", text_col="message", label_col="is_fraud",
                     defaults={"source_type": "real", "language": "ru"})
df.to_csv("data/raw/my_converted.csv", index=False)
```
Импортированные строки получают статус `pending`: их нужно проверить по инструкции разметки.
Если `template_group` нет, группа строится по нормализованному тексту — переводы и перефразировки
затем нужно объединить вручную.

## SMS Spam Collection

Если использовать этот набор, то только как вспомогательный и с `source_type=synthetic`
или отдельной пометкой. «Спам» и «мошенничество» — разные задачи: реклама является спамом, но не мошенничеством.
К тому же набор англоязычный. В текущей версии проекта он не используется.
